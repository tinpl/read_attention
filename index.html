Live probe

A prototype for finding what changes your thinking right now.

Open the prototype

This is a discovery instrument, not a finished trainer. It tests whether a probe can produce an immediate, noticeable change — and whether that change can be named.

What to try

  1. Read the text on the left.
  2. Press Space to switch the probe on and off.
  3. Rate the change and write one sentence about what changed.
  4. Try different forms, motion, and size.
  5. Use the timer (S) to compare reading speed.
  6. Switch the text (T) to see whether the effect survives new material.

Controls

Space probe · 1–9 form · M motion · [ ] size · S timer · R reset · N note · T text · E export

Data

Notes and settings stay in your browser. Export them as JSON from the prototype.
